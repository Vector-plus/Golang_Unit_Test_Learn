## mongo在update时的可选操作符
在 MongoDB 中，除了 `$set`、`$unset` 和 `$inc` 之外，还支持一系列其他更新操作符，用于对文档进行各种修改。以下是一些常用的更新操作符及其用途：

### `$currentDate`

将字段的值设置为当前日期。在选择 `date` 字段类型时，值会以 BSON 日期存储格式存储。

#### 示例

```javascript
db.users.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $currentDate: { lastModified: true, "metadata.lastUpdated": { $type: "date" } } }
)
```

### `$min`

仅在当前字段值大于指定值时，才将字段的值设置为指定的值。

#### 示例

```javascript
db.products.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $min: { price: 20 } }
)
```

### `$max`

仅在当前字段值小于指定值时，才将字段的值设置为指定的值。

#### 示例

```javascript
db.products.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $max: { price: 100 } }
)
```

### `$mul`

将指定字段的值乘以一个数字。

#### 示例

```javascript
db.products.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $mul: { price: 2 } }
)
```

### `$rename`

重命名一个字段。

#### 示例

```javascript
db.users.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $rename: { "oldFieldName": "newFieldName" } }
)
```

### `$setOnInsert`

仅在执行插入操作时，设置字段的值。在使用 `upsert` 时特别有用。

#### 示例

```javascript
db.users.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  {
    $set: { name: "Alice" },
    $setOnInsert: { createdAt: new Date() }
  },
  { upsert: true }
)
```

### `$addToSet`

向数组添加一个元素，如果该元素不存在于数组中。这避免了数组中的重复。

#### 示例

```javascript
db.users.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $addToSet: { interests: "music" } }
)
```

### `$pop`

从数组的起始或末端移除一个元素。`-1` 表示移除数组的第一个元素，`1` 表示移除数组的最后一个元素。

#### 示例

```javascript
db.users.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $pop: { interests: -1 } }
)
```

### `$pull`

从数组中移除所有匹配的元素。

#### 示例

```javascript
db.users.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $pull: { interests: "music" } }
)
```

### `$push`

向数组添加一个或多个元素。可以使用 `$each`、`$slice`、`$sort` 和 `$position` 进行更复杂的操作。

#### 示例

```javascript
// 添加单个元素
db.users.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $push: { interests: "travel" } }
)

// 添加多个元素
db.users.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $push: { interests: { $each: ["reading", "coding"] } } }
)
```

### `$pullAll`

从数组中移除所有指定的元素。

#### 示例

```javascript
db.users.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $pullAll: { interests: ["music", "reading"] } }
)
```

### `$bit`

对整数字段执行位级操作，支持 AND、OR 和 XOR 操作。

#### 示例

```javascript
db.users.update(
  { _id: ObjectId("60ccf437d6a7835e8c9b6c90") },
  { $bit: { flags: { and: 5 } } }
)
```

利用这些操作符，你可以灵活地对 MongoDB 文档进行各种修改操作，能够满足大多数更新需求。希望这些解释和示例能够帮助你更好地理解和使用 MongoDB 的更新操作符。
